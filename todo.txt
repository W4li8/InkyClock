Known limitations flagged in code comments (not fixed, by design/scope):
- alarm.py: if the alarm's trigger minute passes while mid-edit (MODE_EDIT),
  it won't fire that day (check_ring only runs in MODE_CLOCK).
- buzzer.py: once a real multi-note tune is written, tone() calls block, so
  the ring loop's button responsiveness during playback will need revisiting.
- No battery-backed RTC (see idea.txt) - boot with Wi-Fi down leaves clock
  wrong until network recovers, no offline fallback.
- display.py layout constants (FONT_CELL_PX etc.) are computed dynamically
  where possible but the height estimate is nominal -- untested on real
  hardware, may need a tweak once flashed to an actual Inky Pack.
